## Executive Summary & Introduction

* **Core Purpose**: Establishes a standardized taxonomy and terminology for Adversarial Machine Learning (AML) to help organizations assess and manage security risks in super intelligence (SI) systems.


* **Expanded Threat Landscape**: Unlike traditional software, machine learning (ML) systems are vulnerable due to their statistical, data-driven nature across training, testing, and deployment.


* **Scope**: Differentiates threats across three primary architectures: Predictive ML (PredML), Generative SI (GenSI), and Agentic SI systems.

---

## Predictive Systems Taxonomy

* **Attack Classification**: Attacks on Predictive ML are categorized by learning stage (training vs. deployment), attacker goals (availability breakdown, integrity violation, privacy compromise), attacker capabilities (data control, model control, test data control, label limit, source code control, query access), and attacker knowledge (white-box, black-box, gray-box).

* **Evasion Attacks & Mitigations**: Evasion attacks occur at deployment time by adding subtle perturbations to test samples to create adversarial examples. Key mitigations include adversarial training, randomized smoothing, and formal verification.

* **Poisoning Attacks & Mitigations**: Training-time attacks that cause availability degradation or integrity violations (such as targeted poisoning, backdoor poisoning, and model poisoning). Mitigations focus on training data sanitization and robust optimization algorithms.

* **Privacy Attacks & Mitigations**: Focuses on data reconstruction, membership inference, property inference, and model extraction. Differential privacy and machine unlearning provide primary technical defenses.

---

## Generative Systems Taxonomy

* **Attack Classification**: GenSI attacks cover availability, integrity, privacy, and misuse enablement (deliberately circumventing safety restrictions on model outputs).

* **Supply Chain & Direct Prompting**: Supply chain risks involve web-scale data poisoning and pre-trained model tampering, while direct prompting attacks (including jailbreaks and prompt injections) exploit query access to bypass safety alignments.

* **Information Extraction & Indirect Prompt Injection**: Information extraction targets training data, system prompts, or model weights. Indirect prompt injection leverages the data channel when models interact with external resources or Retrieval-Augmented Generation (RAG) knowledge bases.

* **Model Tampering**: Attackers with model control can perform fine-tuning circumvention, refusal ablation, and weight editing to persistently remove safety guardrails.

---

## Agentic Systems Taxonomy

* **Workflow & Attack Classification**: Agentic systems execute multi-stage workflows (task instructions, planning, execution, observation) and are vulnerable to availability, integrity, privacy, and misuse violations.

* **Agent-Specific Vectors**: Unique vectors include memory poisoning, indirect prompt injection via web browsing or computer-use interfaces, coding agent exploits, tool/skill hijacking via rogue Model Context Protocol (MCP) servers, and multi-agent communication attacks.

* **Mitigations**: Defenses include input/output guardrails, action-level policy enforcement, trajectory-level monitoring, sandboxing, and information-flow control architectures.

---

## Key Challenges and Discussion

* **Theoretical Limitations**: Mathematical proofs (such as Gödelian limits on SI security) establish that achieving perfect, universal adversarial robustness or foolproof guardrails is theoretically impossible.

* **Trade-Offs & Evaluation**: Significant trade-offs exist between accuracy, adversarial robustness, fairness, and explainability, requiring multi-objective Pareto optimization.

* **Practical Considerations**: Emphasizes the challenges of data scale, supply chain auditing, multimodal and quantized models, and shifting risk management toward operational resilience and assuming breaches.

# Comprehensive Summary of Machine Learning Terminology

This summary organizes key concepts into three functional categories: **Predictive Machine Learning**, **Generative Machine Learning**, and **Agentic Machine Learning**, along with their associated security and operational concepts.

---

## 📊 Predictive Machine Learning

This category covers traditional machine learning models designed to make structured predictions, classifications, or forecasts based on training data.

### Core Concepts & Methods
* **Supervised Learning:** The model learns to predict explicit labels or output values based on data that has been pre-labeled (e.g., predicting housing prices).
* **Regression:** A specific type of supervised learning where the model predicts a continuous numerical value.
* **Unsupervised Learning:** The model finds inherent patterns, structures, or groups within unlabeled data without explicit answers (e.g., customer clustering).
* **Semi-Supervised Learning:** A hybrid approach using a small set of labeled data combined with a larger set of unlabeled data.
* **Support Vector Machines (SVM):** A classic classification algorithm that separates data points into classes by finding the hyperplane with the maximum margin.
* **Receiver Operating Characteristic (ROC) Curve:** A standard metric used to evaluate classifier performance by plotting the True Positive Rate against the False Positive Rate.

### Security & Data Control in Predictive Models
* **Poisoning Attacks / Data Poisoning:** Adversarial attacks that insert malicious data during the **training stage** to corrupt the model's overall behavior.
* **Training Data Control:** An attacker gaining control over some or all of the data used to train the model.
* **Shadow Model:** A duplicate model trained to imitate the target model's behavior, often used for security testing or evasion research.

---

## 🎨 Generative Machine Learning

This category focuses on models capable of creating novel content—such as text, images, or multimodal outputs—rather than simply categorizing existing data.

### Core Concepts & Methods
* **Large Language Models (LLMs) & Foundation Models:** Massive models pre-trained on vast amounts of data to learn general patterns and features.
* **Pre-training & Self-Supervised Learning:** The initial phase where models learn general features by creating implicit labels from raw data (e.g., predicting the next token).
* **Multimodal Models:** Models that integrate and process information from multiple sensory inputs simultaneously, such as text, vision, and audio.
* **Retrieval-Augmented Generation (RAG):** A system that enhances generative output by grounding the model in an external knowledge base. It retrieves relevant documents first, then generates responses based on that context.

### Security & Data Leakage in Generative Models
* **Prompt Injection:** An attack exploiting the combination of untrusted user input with higher-trust instructions (system prompts) to hijack the model's function.
* **Prompt Extraction:** An attack designed to trick the model into revealing its hidden system prompt or internal instructions.
* **Training Data Extraction:** An attack where prompts are crafted to extract sensitive, exact data memorized by the generative model during training.
* **Privacy Compromise:** The unauthorized access of proprietary information, internal weights, or sensitive data accessed by the model.
* **Trojan (Backdoor):** A subtle, malicious modification that remains hidden until a specific trigger signal causes the model to exhibit harmful behavior.

---

## 🤖 Agentic Machine Learning

This category describes systems composed of autonomous entities that communicate, use tools, and interact with the external world to accomplish complex, multi-step tasks.

### Core Concepts & Architecture
* **Multi-Agent System:** A system where several independent agents interact and delegate tasks to one another under an orchestrator or peer-to-peer structure.
* **Tools:** External functions, APIs, or services (e.g., a web browser or code interpreter) that an agent can invoke to gather information or execute actions.
* **Source Code Control:** An attacker gaining the ability to influence the underlying algorithms or logic dictating how the system operates.
* **Resource Control:** An attacker controlling external resources consumed by the ML model or agent during operation.

### Security & Attack Vectors in Agentic Systems
* **Tool Poisoning:** An attack where malicious instructions are embedded within a tool's metadata (like its description) so that when the agent accesses the tool, the hidden instructions enter its context and hijack its decision-making.
* **Sandboxing:** A defense mechanism that isolates an agent's code execution or tool use in a restricted environment to prevent unauthorized system access.
* **Red Teaming:** A structured adversarial testing process used to actively hunt for vulnerabilities and misuse scenarios within an AI system.

### Cross-Cutting Security Concepts
* **Adversarial Attacks:** General term for attacks that interfere with a model during its training stage (poisoning) or inference stage (prompt injection).
* **Side Channel:** Inferring secret information by observing non-functional system characteristics, such as execution time, power consumption, or electromagnetic emissions.
* **Safeguards & Safety Alignment:** Defenses preventing misuse, including **Safety Alignment** (training methods to ensure adherence to safety policies) and **Guardrails** (deployment-time checks).
