---

## Executive Summary & Introduction

* **Core Purpose**: Establishes a standardized taxonomy and terminology for Adversarial Machine Learning (AML) to help organizations assess and manage security risks in super intelligence (SI) systems.


* **Expanded Threat Landscape**: Unlike traditional software, machine learning (ML) systems are vulnerable due to their statistical, data-driven nature across training, testing, and deployment.


* **Scope**: Differentiates threats across three primary architectures: Predictive ML (PredML), Generative SI (GenSI), and Agentic SI systems.

---

## Predictive Systems Taxonomy

* **Attack Classification**: Attacks on Predictive ML are categorized by learning stage (training vs. deployment), attacker goals (availability breakdown, integrity violation, privacy compromise), attacker capabilities (data control, model control, test data control, label limit, source code control, query access), and attacker knowledge (white-box, black-box, gray-box).

* **Evasion Attacks & Mitigations**: Evasion attacks occur at deployment time by adding subtle perturbations to test samples to create adversarial examples. Key mitigations include adversarial training, randomized smoothing, and formal verification.

* **Poisoning Attacks & Mitigations**: Training-time attacks that cause availability degradation or integrity violations (such as targeted poisoning, backdoor poisoning, and model poisoning). Mitigations focus on training data sanitization and robust optimization algorithms.

* **Privacy Attacks & Mitigations**: Focuses on data reconstruction, membership inference, property inference, and model extraction. Differential privacy and machine unlearning provide primary technical defenses.

---

## Generative Systems Taxonomy

* **Attack Classification**: GenSI attacks cover availability, integrity, privacy, and misuse enablement (deliberately circumventing safety restrictions on model outputs).

* **Supply Chain & Direct Prompting**: Supply chain risks involve web-scale data poisoning and pre-trained model tampering, while direct prompting attacks (including jailbreaks and prompt injections) exploit query access to bypass safety alignments.

* **Information Extraction & Indirect Prompt Injection**: Information extraction targets training data, system prompts, or model weights. Indirect prompt injection leverages the data channel when models interact with external resources or Retrieval-Augmented Generation (RAG) knowledge bases.

* **Model Tampering**: Attackers with model control can perform fine-tuning circumvention, refusal ablation, and weight editing to persistently remove safety guardrails.

---

## Agentic Systems Taxonomy

* **Workflow & Attack Classification**: Agentic systems execute multi-stage workflows (task instructions, planning, execution, observation) and are vulnerable to availability, integrity, privacy, and misuse violations.

* **Agent-Specific Vectors**: Unique vectors include memory poisoning, indirect prompt injection via web browsing or computer-use interfaces, coding agent exploits, tool/skill hijacking via rogue Model Context Protocol (MCP) servers, and multi-agent communication attacks.

* **Mitigations**: Defenses include input/output guardrails, action-level policy enforcement, trajectory-level monitoring, sandboxing, and information-flow control architectures.

---

## Key Challenges and Discussion

* **Theoretical Limitations**: Mathematical proofs (such as Gödelian limits on SI security) establish that achieving perfect, universal adversarial robustness or foolproof guardrails is theoretically impossible.

* **Trade-Offs & Evaluation**: Significant trade-offs exist between accuracy, adversarial robustness, fairness, and explainability, requiring multi-objective Pareto optimization.

* **Practical Considerations**: Emphasizes the challenges of data scale, supply chain auditing, multimodal and quantized models, and shifting risk management toward operational resilience and assuming breaches.

This summary organizes the provided machine learning terminology into three functional categories: 
Predictive Machine Learning, Generative Machine Learning, and Agentic Machine Learning.

***

## 🧠 Predictive Machine Learning
This category encompasses models designed to forecast, classify, or predict specific outcomes based 
on explicit input data and predefined labels.

### Core Techniques & Algorithms
*   **Supervised Learning:** The foundational method where the model learns to predict explicit 
labels or output values using data that is already annotated (labeled).
*   **Regression:** A specific type of supervised learning where the model predicts a continuous 
numerical value (e.g., predicting a house price).
*   **Support Vector Machines (SVM):** Models that classify observations by finding the hyperplane 
that maximizes the margin between different classes.
*   **Unsupervised Learning:** Methods used when data lacks explicit labels. The model learns 
patterns or structure within the data itself, such as clustering or grouping data points.
*   **Self-Supervised Learning:** A training technique where the model generates its own labels from 
unstructured data (e.g., predicting missing parts of a sentence), enabling the use of vast datasets 
without human labeling.
*   **Semi-supervised Learning:** A hybrid method that uses a small amount of labeled data alongside 
a large amount of unlabeled data for training.

### Data Integrity & Limitations
*   **Out-of-Distribution (OOD):** Data collected under conditions different from the data used to 
train the model, which can cause predictive errors when the model encounters unfamiliar inputs.
*   **Testing Data Control:** The capability of an attacker to manipulate the data presented to the 
model during the evaluation or testing phase.

## ✍️ Generative Machine Learning
This category focuses on models designed not just to classify, but to *create* new, original 
content—including text, images, speech, or complex data structures—and the systems that augment 
their capabilities.

### Core Generation Systems
*   **Retrieval-Augmented Generation (RAG):** A system where a generative model is paired with an 
external "knowledge base." When a user asks a query, the RAG system retrieves relevant facts from 
the knowledge base and feeds them to the generative model to ensure the output is factually grounded 
and current.
*   **Multimodal Models:** Models capable of processing and relating information from multiple 
sensory modalities, such as understanding a picture (vision), reading text (language), and 
interpreting spoken audio (speech).
*   **Pre-training:** The initial training stage where a model learns broad, general patterns and 
relationships from massive amounts of unlabeled data, building a foundational knowledge base.

### Interactions & Attacks (LLM Specific)
*   **System Prompt:** High-trust, application-specific instructions provided by the developer to 
guide the behavior of the generative system.
*   **Prompt Injection:** An attack where an attacker exploits the combination of untrusted user 
input and the system prompt to override the intended instructions of the model.
*   **Prompt Extraction:** An attack designed to force the large language model (LLM) to reveal its 
hidden internal instructions or system prompt.
*   **Training Data Extraction:** The ability for an attacker to prompt a generative model to output 
specific, sensitive examples from its original training set.

## 🛠️ Agentic Machine Learning
This category describes systems where the ML model functions as an "agent"—an active entity that can 
perceive its environment, plan multi-step actions, and interact with external tools or services to 
accomplish complex goals.

### Agentic Capabilities & Environment
*   **Agents/Multi-agent System:** A system composed of multiple autonomous software entities that 
communicate and coordinate to complete a task, either by following a single orchestrator or acting 
as peers.
*   **Tools:** External functions or services (e.g., a web browser, file system, code interpreter) 
that an agent can invoke to gather information or take action in the real world.
*   **Resource Control:** The capability of an attacker to manipulate external resources that an 
agent consumes during inference, especially when interacting with tools.
*   **Sandboxing:** A restricted, isolated execution environment used to prevent potentially 
malicious code (like an agent invoking a tool) from accessing system resources beyond what it is 
authorized to use.

### Security & Robustness (Cross-Domain)
The following concepts relate to potential vulnerabilities, attacks, or safeguards across *all* 
machine learning types, but are particularly critical in complex, interacting agentic and generative 
systems:

*   **Poisoning Attacks:** Adversarial attacks that compromise the model during its **TRAINING 
STAGE** by injecting malicious data or modifying the training process.
    *   **Data Poisoning / Targeted Poisoning Attack:** Inserting malicious samples into the 
training data to change specific predictions.
    *   **Model Poisoning:** Altering the model structure or weights during training.
    *   **Tool Poisoning:** Embedding malicious instructions into a tool's documentation so that an 
agent mistakenly uses them.
*   **Trojan / Backdoor:** A hidden, malicious modification to a model that appears harmless during 
normal operation but triggers a desired, malicious behavior only when a specific, rare signal (a 
"trigger") is present.
*   **Privacy Compromise:** The unauthorized leakage of sensitive information from an ML system, 
including proprietary training data, model weights, or sensitive information the model accesses 
(e.g., in a RAG knowledge base).
*   **Side Channel:** Attacks that infer secrets by observing the *non-functional* characteristics 
of the program's execution (e.g., timing, power consumption).
*   **Safeguard / Safety Alignment:** Technical controls (like **GUARDRAILs** or supervised 
fine-tuning) put in place to prevent the model from exhibiting unsafe or malicious behavior as 
defined by its developers.
*   **Red Teaming:** A structured security testing effort using adversarial methods to actively find 
vulnerabilities and unintended risks in the system.
